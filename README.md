# 😴 houses — COMPLETE PROPERTY & TENANT MANAGEMENT SYSTEM

Mrejesho wa Ufungaji na Upelekaji (Deployment Guide):

1. Pakua faili la `houses_project.zip` na ulifungue kwenye kifaa chako (Extract).
2. Unda akaunti ya GitHub na ufungue Repository mpya kwa jina `houses`.
3. Pakia (Upload) faili zote zilizopo hapa kwenye repository yako mpya.
4. Fungua akaunti ya Cloudflare na uende kwenye upande wa **Pages**.
5. Unganisha akaunti yako ya GitHub na uchague repository ya `houses`.
6. Unda Hifadhidata ya D1 kwenye Cloudflare yenye jina `houses_db` na utekeleze amri za `schema.sql`.
7. Unganisha (Bind) hifadhidata ya D1 kwenye Cloudflare Pages ukitumia jina la binding `DB`.
8. Bofya **Deploy** na mradi wako utakuwa hewani!
